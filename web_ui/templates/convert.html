We read every line and turned the ones that describe an action into things a browser can do — clicking, typing, and checking that something is on screen. We call each one a step.

Read down the list the way you’d read your own test script. Where we’ve asked you a question, answer it. Then choose Run the test.

Most lines never become steps. Headings, database setup and expected results have nothing to click, so we keep them beside the test as notes. That’s normal. You’re done when “questions for you” reaches 0.
